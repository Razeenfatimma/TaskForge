# TaskForge

TaskForge is a project-management dashboard with project views, task tracking, a calendar, team management, and browser-local data persistence.

## Run locally

**Prerequisite:** Node.js

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Create a production build with `npm run build`.

The app stores its sample workspace data in your browser's local storage. Use the Settings view to export a JSON backup or restore the sample data.
